Учебный калькулятор на C# и Windows Forms (.NET 8), созданный для кейса № 3 производственной технологической (проектно-технологической) практики.

Возможности:
- Ввод целых и дробных чисел кнопками. Десятичный разделитель — запятая.
- Сложение, вычитание, умножение и деление.
- Последовательные вычисления и использование предыдущего результата.
- Очистка числа и незавершённой операции кнопкой C.
- Обработка деления на ноль, переполнения и некорректных данных.
- Сохранение текущего числа в текстовый файл и его последующая загрузка.
- Переключение размера шрифта дисплея: 16, 20 и 24 пункта.

Для запуска нужны Windows, Visual Studio 2022 с поддержкой .NET 8 и рабочая нагрузка «Разработка классических приложений .NET».
